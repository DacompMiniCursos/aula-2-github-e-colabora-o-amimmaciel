# Aula 2 - GitHub e Colaboracao

Projeto da missao basica da Aula 2 do minicurso Git & GitHub do DACOMP.

## Instalacao

Clone o repositorio e acesse a pasta do projeto:

```bash
git clone git@github.com:DacompMiniCursos/aula-2-github-e-colabora-o-amimmaciel.git
cd aula-2-github-e-colabora-o-amimmaciel
```

## Uso

Este repositorio serve para praticar documentacao no GitHub e organizacao basica de um projeto.

Comandos uteis:

```bash
git status
git log --oneline
```
